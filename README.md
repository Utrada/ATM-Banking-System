🏧 ATM Banking System


💳 A C language-based ATM Banking System project that demonstrates fundamental programming concepts through a simple banking simulation.



📌 Project Overview

ATM Banking System is a console-based application developed in C. It simulates common ATM operations and helps demonstrate programming concepts such as functions, conditions, loops, variables, and menu-driven programming.


✨ Key Features


🔐 PIN-based authentication

💰 Balance enquiry

💵 Cash withdrawal

💳 Deposit functionality

📋 Transaction/menu options

🔄 Multiple banking operations

🖥️ Console-based interface


🛠️ Technologies Used


©️ C Programming Language

💻 GCC / Turbo C / Visual Studio Code

🖥️ Command Line / Console

⚙️ How to Run

Using GCC

gcc atm.c -o atm

Then run:


./atm

Windows

atm.exe
